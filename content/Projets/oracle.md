# L'oracle d'Aaronson

Un petit projet tout gentil pour la fin...

L'oracle d'Aaronson est un petit programme capable de prédire si une personne va taper "g" ou "h" sur son clavier avec une précision généralement supérieure à 60%.


L'idée du programme de base :

- Pour chaque mot possible de 5 lettres ("g" ou "h") entré par l'utilisateur, on tient à jour dans un registre la lettre que l'utilisateur tape tout de suite après.
- Il suffit ensuite de générer une prédiction pour les 5 dernières lettres qui ont été entrées en regardant quelle lettre est majoritairement donnée après ce mot.

1. Écrire le programme.
2. Comment pourrait-on l'améliorer ?
